# 개발 과정과 개인 기여

[SPOT-DETR 프로젝트 페이지](../SPOT-DETR.md) · [홈](../README.md)

## 연구 수행 범위

엄기원이 연구 문제 정의, 방법 설계, 구현, 데이터 구성, 비교·분석 실험, 시각화, 원고 작성을 수행했습니다. 원고에는 엄기원·박천음이 공동 제1저자로 표기되어 있습니다. 이 문서는 본인의 수행 업무를 정리하며, 원고의 공동 저자 표기를 유지합니다. 연구는 2026.10.22 기준 투고 전입니다.

## 1. 모델의 한계를 구체적인 질문으로 바꾸기

작은 객체의 누락을 단순히 특징 표현이 부족하다는 말로 정리하지 않고, **객체 단서가 어느 해상도에서 남는가**, **디코더에 전달하는 초기 후보가 얼마나 정답에 가까운가**로 나누었습니다. 예측 상자에서 발견한 현상을 초기 후보의 재현율과 중심 오차로 이어서 조사했습니다.

산출물은 원고 1절의 문제 분석, 그림 1, 표 5의 초기 후보 분석입니다.

## 2. 기존 모델을 기반으로 수정 지점을 제한하기

SMWG-DETR의 기존 스펙트럼 변조·웨이블릿 융합·잡음 제거 학습을 기반으로 두고, X₂ 경로와 SGS·ATOM을 추가했습니다. 구조를 확장할 때에는 특징 크기와 디코더 메모리, 초기 후보의 출처를 함께 맞추어야 했습니다.

구현에서 중요한 연결은 **융합 전 X₂의 SGS**와 **융합 후 P₂의 ATOM**입니다. 두 모듈을 같은 위치에 독립적으로 붙이는 구조가 아니라, 앞 단계의 특징을 뒤 단계의 후보 생성에 연결하는 직렬 경로입니다.

산출물은 그림 2–4와 [구조 설명](design.md)입니다.

## 3. 비교·반복 실험으로 결과 정리하기

원고의 비교 프로토콜은 공식 train+validation과 test 분할을 사용하며, 각 모델을 40에포크 학습한 결과를 비교합니다. SPOT-DETR은 3개 시드의 평균과 표준편차를 보고했습니다. 구성요소와 후보 분석은 시드 42 모델로 수행하여 반복 평균과 구분했습니다.

산출물은 원고 표 1–6이며, 이 포트폴리오에서는 [CSV](../results/README.md)로도 제공합니다. 표의 단위는 0–100 AP, 비율은 %, 위치 오차는 픽셀로 구분했습니다.

## 4. 설계 의도와 실제 관찰을 구분하기

SGS는 라플라시안에서 유도한 공간 게이트로 국소 잔차를 조절하도록 설계했습니다. 하지만 실제 분석에서는 학습된 게이트가 전경·배경 모두 상한에 가까웠고, 객체/배경 활성도 대비는 기준 모델과 비슷했습니다.

| 관찰 | 해석을 조정한 내용 |
|---|---|
| 특징 맵에서 가까운 객체의 응답 분리가 보임 | 고해상도 경로의 공간 정보 유지에 주목 |
| 전경·배경 대비의 평균 차이가 거의 없음 | 강한 배경 억제를 핵심 효과로 주장하지 않음 |
| 래스터 잔차가 특징 norm의 0.5% 미만 | 밀집 특징의 대체보다 작은 보완으로 설명 |
| +ATOM 전체 AP가 결합 구성보다 0.1포인트 높음 | 결합 구성이 모든 지표를 이긴다고 표현하지 않음 |

## 5. 실패에서 다음 실험을 도출하기

| 현재 제약 | 관찰 근거 | 후속 실험 계획 |
|---|---|---|
| 초밀집 장면의 누락 | 객체 수가 900개 쿼리를 넘는 장면 | 밀도에 따른 쿼리 수 조절 |
| 유사 범주 혼동 | 항만의 배·차량 FP/FN | 주변 문맥을 활용한 분류 보완 |
| 원근·크기 변화 | 비스듬한 드론 촬영 장면 | 원근·스케일 증강 및 별도 촬영 조건 검증 |
| 높은 계산 비용 | 382.4 GFLOPs, 9.14 FPS | 전경 영역 중심 고해상도 처리 |

이 계획은 현재 구현·검증된 성과와 구분합니다. 연구를 통해 얻은 가장 큰 경험은, 구조를 구현하는 일과 함께 **주장의 범위를 실험 근거에 맞추는 일**도 연구자의 역할이라는 점입니다.
