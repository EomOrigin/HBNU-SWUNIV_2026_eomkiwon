# 실험 결과와 해석 범위

[포트폴리오로 돌아가기](../README.md) · [CSV 원자료](../results/README.md) · [연구 원고](../paper/SPOT_DETR_manuscript_20261022.pdf)

모든 수치는 2026.10.22 제공 원고의 표·본문에 근거합니다. AP는 0–100 척도, 비율은 %로 통일했습니다. 예를 들어 원고 표의 0.333은 여기서 AP 33.3입니다. 차이는 AP 포인트 또는 %p이며 상대 증가율과 구분합니다.

## 데이터와 평가 조건

| 항목 | 내용 |
|---|---|
| 데이터 | AI-TOD, AI-TOD-v2 |
| 데이터 관계 | AI-TOD-v2는 AI-TOD와 같은 영상의 주석 수정본 |
| 학습 / 평가 | 공식 train+validation 14,018장 / 공식 test 14,018장 |
| 범주 | airplane, bridge, storage tank, ship, swimming pool, vehicle, person, wind mill |
| 주 지표 | IoU 0.50–0.95를 0.05 간격으로 평균한 AP |
| 크기 구간 | 면적 제곱근 기준 vt: 2–8, t: 8–16, s: 16–32, m: 32픽셀 이상 |
| 출력 / 평가 최대 탐지 수 | 영상당 출력 최대 900개 / 평가 maxDets 1,500 |
| 공통 학습 프로토콜 | 각 모델의 공개 구현·기본 하이퍼파라미터, 40에포크, 마지막 체크포인트 평가 |
| SPOT-DETR 통계 | 표 1–3·6: 3개 시드 평균 ± 표준편차 |
| 구성요소·후보 분석 | 시드 42 모델 사용 |

원고는 위 공통 프로토콜로 비교 모델을 다시 학습했다고 보고합니다. 비교 모델의 시드 간 표준편차는 제공하지 않습니다. 원고 외 원시 로그에 대한 독립적인 재평가는 이번 포트폴리오에 포함하지 않았습니다.

## 구성요소 분석 — 원고 표 4

| 구성 | AP | APvt | APt | APs |
|---|---:|---:|---:|---:|
| 기준 모델 | 29.8 | 15.7 | 30.5 | 33.9 |
| +SGS | 33.2 | 20.7 | 34.3 | 36.0 |
| +ATOM | 33.8 | 20.0 | 34.9 | 36.3 |
| +SGS +ATOM | 33.7 | 21.2 | 35.3 | 36.3 |

기준 모델을 제외한 모든 구성은 X₂ 경로를 포함합니다. 따라서 기준 모델과 +SGS의 차이를 SGS만의 효과로, 기준 모델과 +ATOM의 차이를 ATOM만의 효과로 읽으면 안 됩니다.

+ATOM의 전체 AP가 0.1포인트 더 높지만, 최종 구성은 APvt·APt가 가장 높습니다. +ATOM의 후보 순위 점수 가중치도 0.50으로 기록되어 있어, 최종 구성의 0.25와 구분하고 목적 지표와 함께 고려해야 합니다. 이 표는 반복 평균이 아닌 분석 모델의 결과입니다.

## 초기 후보 분석 — 원고 표 5·4.3.2절

상위 900개 후보에 IoU ≥ 0.5로 겹치는 후보가 하나 이상 존재하는 정답의 비율입니다. 최종 예측의 recall이나 AP와는 다릅니다.

| 모델 / 후보 출처 | vt | t | s | m |
|---|---:|---:|---:|---:|
| 기준 모델 · P₃–P₅ 격자 | 38.5 | 84.5 | 90.3 | 90.2 |
| +X₂ · P₂–P₅ 격자 | 62.8 | 91.2 | 93.0 | 87.6 |
| SPOT-DETR · atom + P₃–P₅ 격자 | 67.1 | 90.8 | 89.8 | 85.5 |
| SPOT-DETR · atom만 | 67.1 | 90.8 | 88.8 | 78.9 |
| SPOT-DETR · P₃–P₅ 격자만 | 0.0 | 2.2 | 18.4 | 53.5 |

SPOT-DETR의 상위 후보에서 very tiny 정답의 재현은 atom 후보가 담당했습니다. 다만 +X₂ 구성보다 t/s/m 재현율은 낮습니다. SGS의 유무도 다르기 때문에 이 감소를 atom 단독 효과로 해석하지 않습니다.

| 추가 분석 | 보고값 | 의미 |
|---|---|---|
| 대응 후보 중심 오차 중앙값 | 기준 1.49 / +X₂ 1.13 / atom 1.00픽셀 | IoU ≥ 0.25 대응 조건 |
| 선택된 atom 비율 | 평균 23.9%, 중앙값 9.5% | 영상별 후보 출처가 달라짐 |
| atom의 셀 중심 이탈 | 평균 0.165셀 | 연속 좌표가 실제 사용됨 |
| 래스터 잔차 상대 크기 | 객체 셀 0.47%, 배경 셀 0.18% | 두 경우 모두 특징 norm의 0.5% 미만 |

## 특징 맵과 SGS 동작

500장의 같은 무작위 test 영상에서 분석한 전경/배경 활성도 대비는 유효 영상 498장 기준 SPOT-DETR **2.083 ± 0.658**, 기준 모델 **2.082 ± 0.651**이었습니다. 영상별 대응 차이는 **0.001 ± 0.336**입니다.

학습된 SGS 게이트도 전경·배경에서 상한 2에 가까웠습니다. 따라서 본 분석은 강한 배경 억제보다 **고해상도에서의 공간 분리**를 뒷받침합니다. 그림의 PCA 정규화된 밝기를 절대적인 활성도 증가로 해석하지 않습니다.

## 효율성과 측정 범위

원고 표 6에서 옮긴 값이며, 실제 측정 기록에서도 기준 모델과 최종 SPOT-DETR의 값을 확인했습니다. 전체 보고값과 각주 표시는 [efficiency.csv](../results/efficiency.csv)에 보존했습니다.

| 항목 | SMWG-DETR | SPOT-DETR |
|---|---:|---:|
| Params | 50.48M | 58.28M |
| GFLOPs | 147.3 | 382.4 |
| FPS | 18.31 | 9.14 |
| Latency | 54.6 ms | 109.4 ms |

측정 기록에서 확인한 조건은 **RTX A6000 1장, batch 1, FP32, TF32·AMP 비활성화, 800×800 입력, warm-up 10회 후 test 영상 500장 평균**입니다. 시간은 host→device 복사·forward·후처리를 포함하고 디스크 I/O·CPU 전처리를 제외합니다. GFLOPs는 fvcore MAC 기준에 커스텀 연산을 포함하며 후처리를 제외합니다. [측정 조건과 원본 로그 발췌 →](../results/efficiency_measurement.md)

전체 비교의 각주도 구분합니다. DQ-DETR·Dome-DETR의 GFLOPs는 동적 쿼리 때문에 20장 평균이며, Dome-DETR-S의 처리 속도에는 공개 구현의 CPU 동기화 비용이 크게 작용합니다. DNTR의 GFLOPs는 1,000개 RoI 기준이어서 실제 test의 최대 3,000개 RPN 제안을 처리하는 비용보다 낮게 추정됩니다.

SPOT-DETR은 정확도 향상을 위해 고해상도 처리 비용을 지불했습니다. 매개변수 +7.80M, 연산량 +235.1 GFLOPs, 지연 시간 약 2배입니다. 실시간·경량 모델이라는 표현을 사용하지 않습니다.

## 정성 그림과 실패 사례를 읽는 방법

그림은 범주 일치 + IoU ≥ 0.5로 예측을 점수 순으로 대응시켜 TP/FP/FN을 구분했습니다. 점수 임계값은 모델별로 test 분할에서 F1이 최대인 값입니다. 따라서 선택된 장면과 이 임계값의 결과는 배포 환경 성능이나 전체 AP를 대신하지 않습니다.

주요 실패 조건은 900개를 넘는 객체가 있는 초밀집 장면, 배·차량 등 유사 범주, 원근·가림이 큰 촬영 장면입니다. test 영상 중 객체가 900개를 넘는 비율은 원고 기준 0.08%이지만 전체 객체의 3.8%를 포함합니다.

이 포트폴리오는 원고 그림 1–4·7·8을 연결합니다. 선택된 정성 비교의 인상보다 전체 실험표, 분석 조건, 실패 양상을 함께 읽는 것을 권합니다.
